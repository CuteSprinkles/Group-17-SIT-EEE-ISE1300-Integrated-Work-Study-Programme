2. What to check first

  1. Read the full message and find that text in the code.
  2. Re-run with CONSOLE_STYLE=debug for the numbers behind it.

3. What the robot is doing right now

  • STOP  wheels stopped, actuator signal released
  • LED   red LED flashing fast (a slow flash is only a lost line, not this)
  • BEEP  repeating rise-and-fall siren
  • FREE  /cmd_vel released after 1.0 s so you can drive it

4. How to recover (drive it yourself)

  1. In TERMINAL 2, start keyboard control: ros2 run turtlebot3_teleop teleop_keyboard
  2. Drive it with the W A S D X keys. The arrow keys do NOT work.
    W forward
    A S D   A = turn left, D = turn right
    X reverse
    S or SPACE = STOP
    Each press changes the target speed and the robot keeps rolling — it does not stop when you let go. Tap S or SPACE to bring it to a halt.
  3. Put the robot back on the line, facing the way it was travelling.
  4. Press Ctrl-C in TERMINAL 2 to close teleop. If you leave it running it will fight this program for control of /cmd_vel.
  5. In TERMINAL 3, run the reset command below.

5. Reset command

ros2 service call /turtlebot3_combined_controller/reset_fail_stop std_srvs/srv/Trigger "{}"

After the reset the robot waits until the Pixy sees the line for a few frames, then carries on by itself.
